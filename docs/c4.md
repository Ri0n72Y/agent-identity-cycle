# C4 Views

本文件用 C4 视角描述长期数字助手与 Reflection Skill 的系统边界。Knowledge Graph、向量索引和 Runtime World Model 被视为外部认知基础设施，它们可以增强检索和上下文装配，但不属于长期主体自身的 canonical content。

## Level 1 — System Context

```mermaid
C4Context
    title Persistent Personal Agent — System Context

    Person(user, "User", "与数字助手长期共同工作、维护文档和项目")
    System(agent, "Persistent Digital Assistant", "通过 Harness 工作，并维护 Memory、Episode、Identity、Facts 与 Procedural Knowledge")
    System_Ext(harness, "Agent Harness", "负责模型、工具、会话与插件组装")
    System_Ext(workspace, "Workspace", "Desktop、Projects、Bookshelves、Logs 等共同维护的内容")
    System_Ext(cognitive, "Optional Cognitive Infrastructure", "FTS、Vector、Knowledge Graph、Runtime Context/World Model")

    Rel(user, agent, "交互、指导、共同工作")
    Rel(agent, workspace, "读取、修改、整理")
    Rel(agent, harness, "通过其运行和调用工具")
    Rel(agent, cognitive, "可选检索与上下文装配")
```

## Level 3 — Reflection Skill Components

```mermaid
C4Component
    title Reflection Skill — Component View

    Container_Boundary(skill, "reflection") {
        Component(entry, "SKILL.md", "Main router", "稳定入口，组织 Short、Episode、Memory、Facts、Identity 与 Procedural 的 consolidation")
        Component(refs, "references/", "On-demand references", "包含标准记忆格式、Episode、Memory、项目状态、Facts、Identity、Procedural 与 Desktop 的整理原则")
        Component(workflows, "workflows/", "Future internal routes", "内部流程复杂到值得独立加载时再增加")
        Component(scripts, "scripts/", "Optional automation", "存在明确重复自动化需求时才增加")
    }

    Container_Ext(files, "Home Files", "Markdown / Git", "Short、Episodes、LTM、Projects Memory、Facts、mPFC、SOUL、PERSONA、Skills 等")
    System_Ext(agent, "Agent Runtime")

    Rel(agent, entry, "激活")
    Rel(entry, refs, "按需读取")
    Rel(entry, workflows, "需要时路由")
    Rel(entry, scripts, "需要时运行")
    Rel(entry, files, "读取并更新 canonical content")
```

这些视图强调一个稳定边界：Reflection Skill 属于长期助手自身的演化机制，而 Knowledge Graph、Vector Store、Runtime World Model 和具体 Harness 都可以替换；长期连续性由人类可读文件和它们的版本历史保存。
