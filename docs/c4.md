# C4 Views

本文件用 C4 视角描述长期数字助手、Short Memory Appending 与 Reflection 的系统边界。Knowledge Graph、向量索引和 Runtime World Model 仍然属于外部认知基础设施；当前持久主体通过一个配置好的绝对 Assistant Home 工作，不为每个项目创建独立本地记忆。

## Level 1 — System Context

```mermaid
C4Context
    title Persistent Personal Agent — System Context

    Person(user, "User", "与数字助手长期共同工作、维护文件和项目")
    System(agent, "Persistent Digital Assistant", "通过 Harness 工作，并维护近期连续性、长期记忆、Episode、Identity 与 Procedural Knowledge")
    System_Ext(harness, "Agent Harness", "负责模型、工具、会话、Subagent 与插件组装")
    System_Ext(workspace, "Workspace", "Desktop、Projects、Bookshelves、Logs 等共同维护的内容")
    System_Ext(cognitive, "Optional Cognitive Infrastructure", "FTS、Vector、Knowledge Graph、Runtime Context/World Model")

    Rel(user, agent, "交互、指导、共同工作")
    Rel(agent, workspace, "读取、修改、整理")
    Rel(agent, harness, "通过其运行并调用工具/Subagent")
    Rel(agent, cognitive, "可选检索与上下文装配")
```

## Level 3 — Maintenance Skill Components

```mermaid
C4Component
    title Memory Maintenance — Component View

    Container_Boundary(shortSkill, "short-memory-appending") {
        Component(shortEntry, "SKILL.md", "Fast maintenance contract", "决定一次完整交互如何形成单条 Short")
        Component(format, "references/memory-format.md", "Shared memory format", "定义 Short 与 Episode 共用索引及 Short Reflection 标记")
    }

    Container_Boundary(reflectionSkill, "reflection") {
        Component(refEntry, "SKILL.md", "Slow consolidation router", "按需处理 pending Short 并路由到较慢结构")
        Component(refs, "references/", "On-demand references", "规定 Episode、LTM、Project、Facts、Identity、Procedural 与 Desktop 的整理原则")
        Component(workflows, "workflows/", "Future internal routes", "内部流程复杂到值得独立加载时再增加")
    }

    Container_Ext(files, "Assistant Home Files", "Markdown / Git", "Short、Memory、Episodes、Identity、Methodology、Skills 等")
    System_Ext(parent, "Parent Agent", "当前用户任务的主要工作上下文")
    System_Ext(subagent, "Maintenance Subagent", "可选短生命周期上下文")

    Rel(parent, shortEntry, "判断是否调用")
    Rel(parent, refEntry, "判断是否立即反思")
    Rel(parent, subagent, "优先委派维护任务")
    Rel(subagent, shortEntry, "执行 Short 写入")
    Rel(subagent, refEntry, "执行慢层 Reflection")
    Rel(shortEntry, format, "读取")
    Rel(shortEntry, files, "更新 short-memory.md")
    Rel(refEntry, refs, "按需读取")
    Rel(refEntry, workflows, "需要时路由")
    Rel(refEntry, files, "读取并更新 canonical content")
```

两个 Skill 的拆分来自不同的运行频率和上下文成本，而不是把同一 Reflection 过程机械拆碎。Short Memory Appending 接近自动维护，但仍由 Agent 决定是否需要写；Reflection 保留更强的主体判断，可以立即执行，也可以等待更多实践积累后再运行。
