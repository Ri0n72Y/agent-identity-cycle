# Facts与工具知识整理原则

## Purpose

Facts 保存已经确认、未来仍值得持续使用的外部事实、项目事实和技术事实，使 Agent 能够在后续工作中直接使用当前有效的认识。

Facts 使用自然语言与文档结构组织，不需要把每条内容拆成 atomic fact、时间字段或数据库 schema。事实发生变化时，长期文档应优先表达当前有效状态；必要的历史变化可以通过已有记录重新追溯，而不需要在正文中同时保留所有旧状态。

工具、软件行为、调用失败、运行环境限制以及已经验证的操作技巧与一般事实有不同的访问需求。当这类信息开始频繁影响实际工作时，可以从一般 Facts 中整理到独立的 Tool Knowledge 文档，使工具知识更容易被 Agent 找到，同时继续保持事实语义。

Tool Knowledge 记录“工具实际上怎样工作”，包括已经验证的参数行为、接口限制、错误原因、环境差异和有效解决方式。它保存可复用的操作事实，但不把这些事实进一步抽象成普遍工作方法。

更新 Facts 或 Tool Knowledge 时优先修订已有相关段落，使文档持续表达当前有效认识。只有在同一主题确实包含彼此独立、需要单独检索的内容时才增加新的小节，避免把长期知识重新写成按时间增长的事件列表。
